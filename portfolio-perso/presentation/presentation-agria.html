Stack technique

Construit avec des technologies robustes

React Native · Expo

App mobile cross-platform iOS & Android. Développée avec Expo, Expo Go pour les tests instantanés sur appareil physique.

Firebase RTDB + AsyncStorage

Fonctionnement hybride cloud/local. Authentification, base de données temps réel et stockage hors-ligne.

Moteur IA embarqué

Base de 15 maladies, scoring de symptômes, recommandations agronomiques ciblées.

OpenWeatherMap · Open-Meteo

Double source météo : données temps réel + prévisions jours à venir avec historique.

Make.com (Integromat)

Automatisation no-code : webhooks pour alertes et rapports de diagnostic détaillés.

Leaflet · ArcGIS · Nominatim

Carte interactive satellite, géocodage OpenStreetMap et dessin de polygones.

Architecture technique

Choix des APIs & services

3 critères : usage terrain · rapport effort / valeur · veille concurrentielle

Critère 1

Usage terrain

L'API doit servir un besoin direct : météo, géolocalisation, synchronisation ou diagnostic.

Critère 2

Rapport effort / valeur

On privilégie les solutions rapides à intégrer, fiables et riches.

Critère 3

Veille techno

Les alternatives moins adaptées sont gardées comme points de comparaison.

Base de données

Firebase Realtime Database

Synchro temps réel · Arborescence /agriaData/ par userId · Profil · Parcelles · Diagnostics · Alertes · Sessions

  • Arborescence /agriaData/

    Clés organisées par userId : profil, champs, diagnostics, alertes, sessions et credentials.

  • Synchro temps réel

    Chaque modification est instantanément propagée à tous les clients connectés via WebSockets.

  • Sécurité par règles RTDB

    Règles : chaque utilisateur accède uniquement à ses données (profils, parcelles, diagnostics). Firebase Auth implémenté.

Automatisation

Make.com — Diagnostic & Alertes IA

Diagnostic culture · Alerte météo → AI Agent agronome → Firebase RTDB

  • Webhook Alerte météo

    Scoring 7 facteurs (température, humidité, gel, pluie, cultures sensibles) envoyé par l'app → traitement IA → alerte enrichie.

  • Webhook Diagnostic

    Culture · Symptômes · Coordonnées GPS — envoyés par l'app Expo pour diagnostic agronomique.

  • AI Agent expert agronome

    Prompt en français : agit comme un expert, croise symptômes observés + météo locale + facteurs de risque → recommandations.

  • Firebase RTDB — écriture directe

    HTTP PUT vers Firebase : les alertes IA et diagnostics sont écrits dans /agriaData/ et affichés instantanément dans l'app.
